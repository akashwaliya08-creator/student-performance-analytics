## Objective

The objective of this project is to develop a Python-based system for analyzing student academic performance.

The program reads student marks and attendance from a CSV file and uses Python, NumPy, and Pandas to perform different calculations and analysis.

## Technologies Used

- Python
- NumPy
- Pandas
- CSV Dataset

## Dataset Description

The project uses a file named `students.csv` containing data of 20 students.

The dataset contains:

- Student ID
- Name
- Department
- Python Marks
- NumPy Marks
- Pandas Marks
- Attendance

## Implementation

The student dataset is loaded using Pandas and stored in a DataFrame.

The program uses functions, loops, and conditional statements to process the student data.

NumPy is used for numerical calculations such as total marks and average marks.

Pandas is used for reading the dataset, filtering records, sorting students, and performing data analysis.

The program calculates:

- Total marks
- Average marks
- Grades
- Pass/Fail status
- Subject-wise averages
- Highest and lowest performers
- Top 3 students
- Class average
- Attendance statistics
- Final student ranking

## Grading System

90 and above: A+  
80 to 89: A  
70 to 79: B  
60 to 69: C  
50 to 59: D  
40 to 49: E  
Below 40: F  

A student is considered passed if the student has at least 40 marks in every subject and at least 75% attendance.
